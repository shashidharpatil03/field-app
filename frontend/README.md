# Frontend

React 19 + Vite. See the [main README](../README.md) for what the app does and how to run it.

```
npm install
npm run dev        # development copy, http://localhost:5173
npm run build      # build the offline-capable copy
npm run preview    # serve the built copy, http://localhost:4173
npm run lint
```

The service worker (offline mode) only runs in the built copy.
